# Контракт данных: «Итоги года»

Данные для модуля, которые возвращает `loadData`. Всё посчитано на нашей стороне: модуль ничего не
считает, только показывает и форматирует. Чего нет в контракте, того модуль не получает.

## Общие правила

- Нет значения — `null`: карточка показывает пустое состояние из макета. Нулевая сумма не
  передаётся, вместо `"0"` приходит `null`.
- Любая карточка может отсутствовать (`null` / пустой список): клиент мог не работать в этом году.
- Суммы — строки. Для форматирования их можно приводить к `number`; арифметики над суммами в
  модуле нет.
- Списки уже отсортированы, порядок не менять.

Не вошло в контракт: условие показа и тексты чёрных карточек («Этот год был фантастический…»)
`TODO(Q3)`; финальные тексты вместо заглушек в макетах `TODO(Q9)`.

## Типы

```ts
/** Сумма в рублях: "1234567.89", "1500". Не отрицательная, до двух знаков после точки. */
type TMoney = string;

/** Сумма, которая может быть отрицательной: "-1500.50". */
type TSignedMoney = string;

/** Процент без знака «%», до одного знака после точки: "20.1", "98". */
type TPercent = string;

type TYearValues = {
  /** Значение за предыдущий год; null — данных нет. */
  previousYear: TMoney | null;
  /** Значение за год итогов. */
  currentYear: TMoney | null;
};

type TClient = {
  /** Для `key`, на экране не показывается. Уникален внутри списка. */
  id: string;
  /** Уже отформатированное название организации или ИП: выводим как есть, не меняя.
   *  До 300 символов, бывают слова без пробелов. */
  name: string;
  /** Сумма поступлений от контрагента за год. Больше нуля. */
  amount: TMoney;
  /** Доля контрагента в выручке клиента за год, например "20.1". Больше нуля. */
  sharePercent: TPercent;
};

type TContractor = {
  id: string;
  /** Отформатированное название, как у `TClient.name`. */
  name: string;
  /** Сумма платежей получателю за год. Больше нуля. */
  amount: TMoney;
  /** Число платежей получателю за год. Целое, больше нуля. */
  paymentsCount: number;
};

type TCashFlow = {
  /** «Поступления». null — «Не было поступлений». */
  receipts: TMoney | null;
  /** «Выплаты». null — «Не было выплат». `TODO(Q5)`: чем отличаются от списаний. */
  payments: TMoney | null;
  /** «Поток»: поступления минус списания. null — «Не было потока». `TODO(Q5)`: показ минуса. */
  net: TSignedMoney | null;
};

type TRevenuePlan = {
  /** План по выручке, заданный клиентом. Больше нуля. */
  plan: TMoney;
  /** Фактическая выручка от продаж за год; null — факта нет. */
  actual: TMoney | null;
};

type TTaxPayments = {
  /** Сумма налоговых платежей за год. Больше нуля. */
  amount: TMoney;
  /** Доля налогов в расходах клиента за год, например "19". От "0" до "100". */
  expensesSharePercent: TPercent;
};

type TTaxFund = {
  /** Открыт ли у клиента фонд «Налоги»; от этого зависит совет в секции. `TODO(Q4)` */
  isOpened: boolean;
  /** Баллы по фонду «Налоги», в рублях; null — «Нет баллов». При isOpened: false всегда null. */
  points: TMoney | null;
};

type TSupport = {
  /** «Обращения за год». Целое, больше нуля; null — обращений не было. */
  requestsCount: number | null;
  /** «Решено с первого обращения», целое от "0" до "100"; null — обращений не было. */
  firstContactResolvedPercent: TPercent | null;
  /** «Частая тема»: формулировка вопроса, показывается в кавычках. Непустая; null — нет данных. */
  frequentTopic: string | null;
};

/** Клиент платил бизнес-картой за год. Вариант выбираем мы. */
type TBusinessCardsWithPayments = {
  kind: 'withPayments';
  /** «Операции по карте». Целое, больше нуля. */
  operationsCount: number;
  /** Магазин, в котором клиент больше всего платил картой; null — нет данных. `TODO(Q7)` */
  topMerchant: string | null;
  /** «Участие в акциях»; null — не участвовал: вместо карточки текст со ссылкой. */
  promotionsCount: number | null;
  /** «Кэшбэк»; null — кэшбэка не было: вместо карточки текст со ссылкой. */
  cashback: TMoney | null;
};

/** Клиент ни разу не платил бизнес-картой за год. */
type TBusinessCardsWithoutPayments = {
  kind: 'withoutPayments';
  /** Сколько клиент вывел на личную карту или снял наличными; null — пустое состояние. */
  personalWithdrawals: TMoney | null;
  /** Сколько кэшбэка вернулось бы при оплате бизнес-картой; null — пустое состояние. */
  potentialCashback: TMoney | null;
  /** Сумма баллов, выплаченных всем клиентам банка. Просто число без единицы («198»). */
  pointsPaidToAllClients: number | null;
  /** Предложения партнёров, которыми клиент не воспользовался. Пустой — блок не показывается. */
  unusedPartnerOffers: ReadonlyArray<string>;
};

type TYearlyReportData = {
  /** Год итогов, например 2026. Предыдущий год — year - 1, год в финале — year + 1. */
  year: number;
  /** «Выручка». «Главные итоги»: currentYear; «Выручка и депозиты»: карточки двух лет. */
  revenue: TYearValues;
  /** «Списания». «Главные итоги»: currentYear; «Расходы и денежный поток»: карточки двух лет. */
  expenses: TYearValues;
  /** «Контрагенты» в «Главных итогах». Целое; null — «В этом году у вас не было контрагентов». */
  counterpartiesCount: number | null;
  /** «Экономия». `TODO(Q5)`: определение не задано. */
  savings: TMoney | null;
  /** «Доход на депозитах» («Фактическая выгода», «Выручка и депозиты»). */
  depositIncome: TMoney | null;
  /** Фонд «Налоги»: «Налоги и баллы»; баллы также в «Фактической выгоде» `TODO(Q5)`. */
  taxFund: TTaxFund;
  /** «Топ контрагентов»: от 0 до 3. Заголовок по числу: «Топ-3» / «Топ-2» / «Главный». `TODO(Q8)` */
  topClients: ReadonlyArray<TClient>;
  /** «Топ получателей»: от 0 до 3, заголовки как у topClients. `TODO(Q8)` */
  topContractors: ReadonlyArray<TContractor>;
  /** Блок «ОДДС» в «Расходах и денежном потоке». */
  cashFlow: TCashFlow;
  /** «План/факт»; null — план не задан. `TODO(Q5)`: что показывает карточка. */
  revenuePlan: TRevenuePlan | null;
  /** «Налоговые платежи»; null — «Не было налоговых платежей». */
  taxPayments: TTaxPayments | null;
  /** Секция «Обращения». */
  support: TSupport;
  /** Секция «Бизнес-карты». */
  businessCards: TBusinessCardsWithPayments | TBusinessCardsWithoutPayments;
};
```

## Действия

Нажатие на кнопку или ссылку, которая ведёт за пределы модуля, сообщается в `onAction`.

```ts
type TYearlyReportAction =
  /** «Подключить другие банки» в «Главных итогах». Условие показа: `TODO(Q6)`. */
  | 'connectBanks'
  /** «Узнать больше» в «Бизнес-картах». */
  | 'learnMoreCards'
  /** «Забрать подарок» на финальном экране. */
  | 'claimGift'
  /** «Успеть забрать подарок» в «Бизнес-картах» (kind: 'withoutPayments'). */
  | 'claimGiftBeforeEnd'
  /** Ссылка «актуальную информацию» в тексте про акции. */
  | 'promotionsInfo'
  /** Ссылка «Подключите ПЛку» в тексте про кэшбэк. */
  | 'connectCashback';
```

Ссылки в «Вам совет» («Бюджет», «получить бонус») добавим после решения `TODO(Q4)`.

## Форматирование

В числе не больше **трёх цифр**, дальше сокращённая единица. Десятичный разделитель — запятая,
между числом, единицей и «₽» — неразрывные пробелы, нули в конце дробной части убираются.

**Суммы (`TMoney`).** Округлить до целого рубля (половина вверх), выбрать единицу, округлить число
до трёх значащих цифр. Если получилось 1000 — взять следующую единицу.

| Сумма, ₽ | до 999 | до 999 999 | до 999 999 999 | до 999 999 999 999 | дальше |
| --- | --- | --- | --- | --- | --- |
| Единица | ₽ | тыс ₽ | млн ₽ | млрд ₽ | трлн ₽ |

| Сумма | Показывается | Сумма | Показывается |
| --- | --- | --- | --- |
| `"0.40"` | 0 ₽ | `"700000"` | 700 тыс ₽ |
| `"950"` | 950 ₽ | `"999600"` | 1 млн ₽ |
| `"1000"` | 1 тыс ₽ | `"1250000"` | 1,25 млн ₽ |
| `"1234.56"` | 1,23 тыс ₽ | `"12345678"` | 12,3 млн ₽ |
| `"80000"` | 80 тыс ₽ | `"1500000000"` | 1,5 млрд ₽ |
| `"99960"` | 100 тыс ₽ | `"999999999999.99"` | 1 трлн ₽ |

**Количества (`number`).** Те же три цифры, единица «тыс.» или «млн», без «₽»: `198` → 198,
`1200` → 1,2 тыс., `18000` → 18 тыс., `2500000` → 2,5 млн. Существительное после числа до тысячи
склоняется по числу («1 платёж», «2 платежа», «8 платежей»), после «тыс.» и «млн» — родительный
падеж множественного числа («18 тыс. платежей»).

**Проценты (`TPercent`).** Одна цифра после запятой, если она не ноль, неразрывный пробел перед
«%»: `"20.1"` → 20,1 %, `"98"` → 98 %, `"19.0"` → 19 %.
